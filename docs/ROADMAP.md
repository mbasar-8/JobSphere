# JobSphere Roadmap

## Overview

This roadmap outlines the completed features in Version 1 and the planned improvements for future releases of JobSphere.

The project will continue to evolve with new features, performance enhancements, and user experience improvements while maintaining a clean and scalable architecture.

---

# Version 1.0.0 (Completed)

## Authentication

- User registration
- Email OTP verification
- Login and logout
- Laravel Sanctum authentication
- Role-based authorization

---

## Candidate

- Candidate profile management
- Browse published jobs
- View job details
- Apply for jobs
- Withdraw applications
- Save and remove saved jobs
- Candidate dashboard

---

## Recruiter

- Recruiter profile management
- Company management
- Create job postings
- Update job postings
- Publish jobs
- Close jobs
- Review candidate applications
- Update application status
- Recruiter dashboard

---

## Platform

- RESTful API
- PostgreSQL database
- Laravel Form Request validation
- API Resources
- Pagination
- Production deployment
- Project documentation

---
